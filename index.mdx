DHTMLX Gantt is an open-source JavaScript library for building interactive Gantt charts. It handles project timelines, task hierarchies, dependency links, and drag-and-drop scheduling out of the box — and works with plain JavaScript as well as React, Angular, Vue, and Svelte.

## Get Started in Three Steps

<Steps>
  <Step title="Install the package">
    ```bash
    npm install dhtmlx-gantt
    ```
  </Step>
  <Step title="Import and add a container">
    ```js
    import { gantt } from "dhtmlx-gantt";
    import "dhtmlx-gantt/codebase/dhtmlxgantt.css";
    ```
    ```html
    <div id="gantt_here" style="width:100%;height:600px;"></div>
    ```
  </Step>
  <Step title="Initialize and load data">
    ```js
    gantt.config.date_format = "%Y-%m-%d";
    gantt.init("gantt_here");
    gantt.parse({
      data: [
        { id: 1, text: "Project", type: "project", open: true },
        { id: 2, text: "Task A", start_date: "2026-06-01", duration: 5, parent: 1 },
        { id: 3, text: "Launch", start_date: "2026-06-06", type: "milestone", parent: 1 }
      ],
      links: [{ id: 1, source: 2, target: 3, type: "0" }]
    });
    ```
  </Step>
</Steps>
