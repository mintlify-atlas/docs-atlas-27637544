DHTMLX Gantt is an open-source JavaScript Gantt chart library for building interactive project timelines. It ships as the `dhtmlx-gantt` npm package (version 10.0.1) under the **MIT License** with fully readable TypeScript and JavaScript source code you can fork, modify, and rebuild. It is framework-agnostic and works with plain JavaScript as well as React, Angular, Vue, and Svelte.

## Key Features

The Community Edition covers the complete everyday Gantt feature set, including projects (summary tasks) and milestones.

Additional capabilities in the full feature list include:

- **Lightbox task editor** — configurable modal dialog with support for custom controls
- **Multiple chart instances** — render several independent Gantt charts on one page via the `Gantt` factory
- **Templates** — override any rendered element (bars, grid cells, scale cells, tooltips)
- **Grid column resizing** and a column-configuration API
- **Event system** — 100+ events covering interactions and lifecycle hooks
- **WAI-ARIA accessibility**, touch support, and CSP-compliant mode
